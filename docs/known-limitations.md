# Known limits and evidence boundaries

blendsmith is an instruction package. It does not install Blender, supply a universal mesh generator, recover hidden geometry from a single photo, or guarantee artist-level reference matching.

- Complex irregular silhouettes and transitions require proportion review before detail.
- Intricate hinge construction and collision-free movement need asset-specific reference and pose tests.
- Screen/view-dependent optical effects may remain visually approximate even when controls work.
- One atlas may not supply enough texel density for every close-up; confirm tradeoffs rather than silently adding maps.
- Valid topology counts, UV existence or a beauty render alone cannot certify quality.
- Tool availability, permissions, render hardware and compatible Blender version must be checked per environment.
- Document validation only checks the supported repository conventions; it does not parse every possible Markdown/YAML construct or test Blender assets.

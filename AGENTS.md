# blendsmith repository instructions

- Read `skill/blendsmith/SKILL.md` for asset work and relevant rules when editing the specification.
- English is authoritative; synchronize the Traditional Chinese copy when behavior changes.
- Preserve rule IDs and historical outcomes. Keep specific asset budgets and mechanics local.
- Follow CONTRIBUTING.md and add a unique change record for substantive edits. Do not change release versions without maintainer authorization.
- Run `python scripts/validate.py` for repository changes; report Blender tests separately.
- Reuse a configured worklog directory; otherwise use `worklog/` in the current project. Worklogs are ignored by Git by default, not public evidence.
- Do not modify models, publish, install globally, or delegate to other agents unless the user's task authorizes it.
